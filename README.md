# Walking

Turn noclip into walking in [FRUKT](https://store.steampowered.com/app/3880400/FRUKT/) by [Phoenix557](https://github.com/Phoenix557). Move with WASD, sprint with Shift, and jump with Space. Noclip stays on a hotkey, and that key can be changed in the pause menu.

## Prerequisites

Install these before `Walking.dll`. Walking does not start correctly without them.

1. **[FRUKT](https://store.steampowered.com/app/3880400/FRUKT/)**, the Steam game by tripledose.
2. **[MelonLoader](https://melonwiki.xyz/#/)** installed on that game. In the installer, pick `FRUKT.exe`.
3. **[Phx Pause Menu](https://github.com/Phoenix557/Fruckt-PhxPauseMenu)** (`Phx.dll`) in the same `Mods` folder. Walking registers its noclip key with Phx. Without `Phx.dll`, the mod has no settings page and will not load its hotkey. Pause the game and open **PHX PAUSE** to change it.
4. **[Walking](https://github.com/Phoenix557/Frukt-Walking)**.

## Install

1. Close FRUKT. The game locks files in `Mods` while it is running.
2. Put `Phx.dll` in `Mods` if it is not already there.
3. Put `Walking.dll` in that same folder.

Steam's default folder is:

```
C:\Program Files (x86)\Steam\steamapps\common\FRUKT\Mods
```

4. Start FRUKT.

Walk with **WASD**, sprint with **Shift**, and jump with **Space**. Noclip defaults to **V**. Change that key under **PHX PAUSE**.

## Update

Close FRUKT, replace `Walking.dll` in `Mods`, and start the game again.
